# Antonio Lamb

Molecular biologist and entrepreneur in Basel. I move biology off the bench and into
software: instrument drivers, lab automation, and bioinformatics that runs on hardware
you already own.

### Current focus

- Building [Lambda Biolab](https://github.com/Lambda-Biolab), a BSL-1 shared lab and open
  tooling for bioengineering, since 2022.
- Reverse-engineering lab instruments into open Python APIs, from PCR machines to plate
  readers to electronic pipettes.
- Running local LLM inference and agent tooling for wet-lab workflows.

### Selected work

**Variant calling on small hardware**

- [**deepvariant-linux-arm64**](https://github.com/Lambda-Biolab/deepvariant-linux-arm64):
  DeepVariant on Graviton, Ampere, RK3588, and Jetson via ONNX Runtime + ACL.
- [**deepvariant-macos-arm64-metal**](https://github.com/Lambda-Biolab/deepvariant-macos-arm64-metal):
  Apple Silicon variant caller with Metal, CoreML, and a fast pipeline.
- [**vastai-gpu-runner**](https://github.com/Lambda-Biolab/vastai-gpu-runner): batch GPU
  orchestration on Vast.ai with R2 storage and crash recovery.

**Instrument control and lab automation**

- [**bentolab**](https://github.com/Lambda-Biolab/bentolab): reverse-engineered BLE/Wi-Fi
  protocol for Bento Lab PCR workstations, with async client, FastAPI wrapper, and CLI.
- [**wallac-victor2-api**](https://github.com/Lambda-Biolab/wallac-victor2-api): REST/JSON
  API for a PerkinElmer Victor2 multimode plate reader, driven from Linux.
- [**dpette-usb-driver**](https://github.com/Lambda-Biolab/dpette-usb-driver): open USB
  driver for DLAB dPette electronic pipettes.
- [**i3mega-pipettebot**](https://github.com/Lambda-Biolab/i3mega-pipettebot): an Anycubic
  i3 Mega turned into a sub-$150 disposable-tip pipetting robot.

**Structure prediction and agents**

- [**biolab-runners**](https://github.com/Lambda-Biolab/biolab-runners): modular runners for
  Boltz-2 structure prediction and OpenMM MD.
- [**bioml-commons**](https://github.com/Lambda-Biolab/bioml-commons): shared research,
  infrastructure, and tooling for computational drug discovery.
- [**lab-copilot-gateway**](https://github.com/antomicblitz/lab-copilot-gateway): policy and
  audit gateway for an eLabFTW lab copilot.
